## 🚀 Quick Start (3 steps)

### 1. Get OMDB API Key
```
Visit: http://www.omdbapi.com/apikey.aspx
Register → Get Key
```

### 2. Configure
```javascript
// In app.js, line 17
API_KEY: 'your_key_here'
```

### 3. Run
```bash
python -m http.server 8000
# Open: http://localhost:8000
```
